# C13 — Đóng xem flow

Detached preview control bar
→ Đóng xem
→ _close_detached_preview(user_initiated=True)
→ close detached preview items / DWM overlay resources
→ stop presenting detached-view lifecycle

Not the same as:
- Hủy tách: separate visible action
- ↺ refresh: closes then reopens preview
- Đóng hết: closes actual game windows (C16)

Explicit unknown: exact secondary state changes in user_initiated branch and exact embedded-preview restoration difference vs Hủy tách.
