## Concrete issue identified in already reconstructed native code

`C12HideAll.show_documented_origin` originally called `allowed()` on entry, before each real `SetWindowPos`, and after all moves. The entry path caught arbitrary `Exception`, but later checks caught only a limited list (`OSError`, `RuntimeError`, `TypeError`, `ValueError`, `KeyError`). Unexpected provider exceptions such as `AssertionError` after one or both actual HWND moves could escape before `stop()` marked PARTIAL, leaving `_state == HIDDEN` even though one/two Win32 windows had moved. A subsequent call could then act on false bookkeeping. **This is a defect in the reconstruction's safety fence, NOT a verified original TLM bug.**
