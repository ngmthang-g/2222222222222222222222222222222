# B01 — Chốt kích thước cửa sổ chính

## STATUS
**VERIFIED — HIGH CONFIDENCE**

B01 chỉ đo giao diện từ bộ ảnh TLM gốc do người dùng cung cấp. Không chạy binary và không suy đoán kích thước bị che khuất.

## Evidence set

Đã đo **12 screenshot** TLM. Tất cả đều có raster:

- **452 × 1032 px** toàn cửa sổ (outer window)
- **450 × 1000 px** vùng client/content

Có 11 raster hash duy nhất; 2 ảnh Train LSV là bản trùng byte, nhưng điều này không ảnh hưởng phép đo.

## Pixel boundary measurement

Trong toàn bộ ảnh:

- cột ngoài trái: `x = 0`
- client bắt đầu: `x = 1`
- client kết thúc: `x = 450`
- cột ngoài phải: `x = 451`

=> client width = **450 px**

Theo chiều dọc:

- outer top: `y = 0`
- title-bar/non-client area kéo đến `y = 30`
- client bắt đầu: `y = 31`
- client kết thúc: `y = 1030`
- bottom frame: `y = 1031`

=> client height = **1000 px**

## Locked B01 baseline

| Metric | Baseline |
|---|---:|
| Client/content width | **450 px** |
| Client/content height | **1000 px** |
| Observed outer width | **452 px** |
| Observed outer height | **1032 px** |
| Observed horizontal non-client overhead | **2 px total** |
| Observed vertical non-client overhead | **32 px total** |

For reconstruction, the UI baseline target is therefore **450 × 1000 client pixels**. Under the exact Windows decoration/theme represented by the screenshots this appears as **452 × 1032 outer pixels**.

## Confidence / limitations

### VERIFIED from screenshots
- 12/12 supplied captures have the same outer raster dimensions.
- Full left/right/bottom window boundaries and complete title bar are visible.
- Pixel boundaries support a 450 × 1000 client region consistently.

### UNKNOWN / not claimed by B01
The screenshots alone do **not** prove:
- the exact code/API used to set geometry;
- that the source literally calls a geometry string such as `450x1000`;
- the Windows DPI/scaling percentage;
- whether the window is resizable;
- min/max size constraints;
- initial X/Y screen position;
- whether dimensions change under another Windows theme/DPI configuration.

Those values remain **UNKNOWN** until separately evidenced.
