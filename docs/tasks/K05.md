## 4. First item use has two send attempts

The target-acquisition block contains:
- `_att`;
- `_used`;
- exact failure text `gửi lệnh dùng thất bại lần ... /2`;
- final `gửi lệnh dùng thất bại → skip vòng`.

Thus:
1. locate current item row / dbID;
2. try internal use;
3. retry once if send fails;
4. after **2 total attempts**, skip the current Trừng Ác cycle.

Use exceptions are logged and do not convert this send failure into the no-item terminal state.

## 11. Stop versus ordinary travel failure

Exact stop log:

`bay tới mục tiêu bị stop (...) `
