- _name_to_coords resolves built-in sell, built-in Dồn/receive, or manual saved presets to (map_id,x,y), otherwise None.

- Old Bán <map> config names are normalized to current bare sell-map names when valid.
- Current Tọa độ dồn is one shared _recv_coord_var above receiver rows. Receiver rows only select account + delete and reference the same shared variable for compatibility.
- The account coordinate selector is role-dependent: receiver -> sell builtins + manual; donor -> manual train presets.
- Saved-row Train button applies the preset name to train selectors for all accounts.
- [DonVang] coordinate persistence is coord_<n>=preset_name|map_id|x|y; map save/load uses coord_id_for_name / coord_name_for_id with stale/unknown records skipped, not guessed.
- Per-account coordinate selection key is acc_<character>_farm.
- Receiver config surface includes recv_count, recv_<n>_acc, recv_<n>_coord, receiver, recv_coord; exact conflicting legacy/per-row precedence is deferred to L06.
- No dedicated numeric validator/range clamp is recovered for coordinate X/Y.
- Packaged log has no correlated Dồn coordinate trace, so runtime parity remains environment-required.
