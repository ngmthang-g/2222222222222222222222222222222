## 2. Implementation
New `src/input_sync_core.py`:
- `ClientSize` with strictly positive integral client dimensions, `scale_client_point` based on the actual master/slave client RECT ratio. S19 uses a **LOCAL integer-floor/clamp rule**, not a recovered original rounding formula; refuses coordinates outside the master client instead of wrapping.
- `InputSyncModel` is a bounded **pure, explicit-sink-only planning/dispatch** model. `start()` verifies valid immutable S09 snapshot, unique positive HWND/PIDs, S08 game candidate identity, current master generation, at least one slave and positive max-window value. This does not grant real server entitlement — production must eventually connect an independent genuine token/heartbeat and native HWND identity backend.
- `queue_mouse` appends complete per-slave down/up batches with monotonically increasing sequence and model generation. It does **not** send any event when enqueued, rejects duplicate press/orphan release, bad button or missing geometry. `dispatch_one` requires all THREE explicit callbacks: test-only sink, live identity validator and permission validator; rechecks master/target HWND/PID before each FIFO item and cancels remainder if invalid. There is intentionally **no native input sender**.
- `master_changed()` / `stop()`: cancel queued events, clear logical tracked buttons and invalidate old generation, never automatically re-enable. C19 `watchdog(10s)` only clears S19 **logical** queued/pressed model state; it does **NOT** claim to release native DLL-blocked slave input (no such lock is taken).
- `NativeClientRectReader`: real, strictly **read-only** Win32 `GetClientRect`, `IsWindow`, current HWND/PID checks before/after. It never posts input, hooks keyboard/mouse, injects DLL or changes windows.
- Constants reflect original C19 input-side keepalive 1.5s and watchdog 10s; exact original keyboard payload/move throttle are explicit UNKNOWN, not implemented.
- No existing original specimen, source shell, Start, preview, S17 layout, S18 settings, tests or Proxy modified.
