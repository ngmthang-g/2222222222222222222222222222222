# A05 — Xác minh launcher ngoài và EXE trong `.dist`

## STATUS
VERIFIED

## METHOD
Static-only analysis. No package executable was launched.

The embedded AutoHotkey source text was recovered directly from the outer `TLMTool.exe` bytes and matched against the actual package layout.

## VERIFIED RELATIONSHIP
The root `TLMTool.exe` is an AutoHotkey 1.1.37.02 launcher wrapper. Its embedded script performs this exact control flow:

1. If the launcher is not elevated, it relaunches its own `A_ScriptFullPath` with `*RunAs` and exits the non-elevated instance.
2. It sets `scriptDir := A_ScriptDir`.
3. It builds `exePath := scriptDir . "\TLMTool.dist\TLMTool.exe"`.
4. It builds `workDir := scriptDir . "\TLMTool.dist"`.
5. It checks `FileExist(exePath)`.
6. If present, it executes `Run, %exePath%, %workDir%`.
7. If missing, it shows `MsgBox, Không tìm thấy file: %exePath%`.

Therefore the relationship is VERIFIED:

`root TLMTool.exe` → elevation wrapper → `TLMTool.dist\TLMTool.exe`

with the working directory set to `TLMTool.dist`.

## PACKAGE PATH CHECK
The target path encoded by the launcher exists in the supplied package:

- Outer launcher: `TLMTool_2.1.2/TLMTool.exe`
- Inner target: `TLMTool_2.1.2/TLMTool.dist/TLMTool.exe`
- Working directory: `TLMTool_2.1.2/TLMTool.dist`

## ADDITIONAL STATIC FACTS
- The outer wrapper does not use `RunWait`; the recovered script contains only `Run` for the inner target after the existence check.
- No command-line argument forwarding to the inner executable is present in the recovered launcher script.
- The wrapper uses `#NoTrayIcon` and `#SingleInstance Force`.
- The outer executable manifest requests `asInvoker`; elevation is requested by the script itself through `*RunAs` when `A_IsAdmin` is false.
