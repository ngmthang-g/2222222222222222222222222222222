## 5. Current-cycle skip conditions

Verified current-cycle skips include:
- low-HP heal failure at cycle start;
- move-to-bổ-đầu failure/timeout/wrong-map;
- target-use packet failure after two attempts;
- target travel failure;
- missing Trừng Ác Lệnh at summon stage;

These do not by themselves complete the whole Trừng Ác session.

## 6. Recover-next-cycle conditions

Target coordinates missing:
- cancel current quest;
- start a fresh outer cycle.

Repeated same-target stuck condition:
- once the hidden threshold is reached, cancel the quest;
- reset tracking;
- proceed to a later outer cycle.

## 7. Fail-soft paths

Verified fail-soft behavior includes:
- reinjection failure before NPC movement -> direct movement still attempted;
- reinjection failure before healing -> direct movement still attempted;
- 30/30 dialog read/click failure -> treat as not-full and continue;
- start_auto_train failure -> fight window still continues;
- final heal failure -> log and finish the cycle tail;
- discard child failure -> account-local log/count; other account discard threads continue.

These behaviors must not be upgraded into hard stops during parity reconstruction.

## 8. Recoverable interrupt paths

Death/Địa phủ:
- combat can break early on death;
- _diaphu_monitor polls every 4 seconds;
- HP0 clicks (792,441);
- MapID 87 sets respawn_event;
- next cycle clears respawn_event so healing/movement can leave map 87.

Disconnect:
- _punish_disconnect_monitor polls every 2 seconds;
- memory-connected True vetoes false-positive disconnect;
- both exact disconnect pixels must persist 3 ticks;
- confirmation signals halt and clicks (616,455);
- activity-wide path waits up to 60 seconds;
- single-row path waits for common.active, invalidates Reader cache, then wait_memory_ready(timeout=45, need=3).

Successful recovery resumes Trừng Ác from a fresh outer-cycle boundary instead of pretending the interrupted statement continued in place.

## 9. Background discard lifecycle

Discard is run-scoped, not cycle-scoped.

While Trừng Ác accounts are active and the persisted checkbox is armed:
- only running/non-disconnected Trừng Ác HWNDs are eligible;
- each eligible account gets its own child thread;
- inflight prevents overlapping passes for the same account;
- shared bag_filter has a lower per-HWND packet lock;
- discard uses command 100005 action 4 and full-stack dbID semantics;
- packet pacing is 1 second per account.

Do not append discard as a fixed post-combat step.

## 10. UI and stop handoff

- running: Dừng lại / FireBrick;
- stopping: Đang dừng... / disabled;
