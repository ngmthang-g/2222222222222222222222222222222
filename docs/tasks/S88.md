## ACTUAL REPRODUCIBLE LOCAL GAP
In existing `TLMStartTab._sync_tiles` (automatic C04 scan/UI update), a removed/reused HWND set caused:
```python
if self._preview_controller is not None and old_keys - wanted:
    self._preview_controller.clear()
```

This previously escaped the **automatic** Tk callback before releasing old preview frames and without setting the S76 lifetime fault fence.
