## 2. Confidence legend

The architecture diagram uses four edge meanings:

- **A / solid** — contextual/call-direction evidence recovered from symbols/docs/state references.
- **B / dashed** — D02 static compiled-module reference; directional block reference but **not import proof**.
- **Protocol / thick** — explicit RPC/HTTP/ADB/helper protocol.
- **Data / dotted** — persisted/config/resource relationship.

The diagram must not be read as a literal Python import graph.

### Injected payload boundary

`data/resources.dat` is the active x64 PE DLL-format injected payload.

It is **not** ordinary data. It exposes hook/message functions used by game/input integration.

`version.dat` is a separate version.dll-compatible proxy payload.

## 8. Emulator architecture

Two parallel guest interaction paths exist.

### A. Frida memory path

```text
PC emu_reader / manager
        │
        ▼
ADB / guest frida-server
        │
        ▼
emu_client.js resident script
        │
        ▼
rpc.exports
        │
        ▼
Android game process memory
```

The JS exports player discovery/read/validation and bag-slot counting.

### B. Remote overlay/action path

```text
ld_remote.js AutoX floaty
        │ HTTP JSON
        ▼
PC emu_remote ThreadingHTTPServer
        │
        ├── emu_input
        ├── emu_reader / manager
        ├── farm_data
        ├── train_lsv_tab
        └── permission_guard
```

Protocol:
- bind `0.0.0.0`
- default port `8765`
- default token `tlm`
- emulator identity primarily by guest/peer IPv4.

A secondary data bridge is:

`/sdcard/TLM/tlm_<aid8>.json` ←→ PC ADB pull.

## 9. Proxy / network helper architecture

```text
Login / Proxy / FastTravel
        │
        ├── runtime forwarder*.txt / proxy*.txt state
        ▼
forwarder.exe
        │ local SOCKS forwarder
        ▼
Default.ppx / Proxifier
        │
        ▼
game network traffic
```

`forwarder.exe` supports SOCKS4/SOCKS5/HTTP CONNECT and proxy target rotation/pinning/bad-list behavior.

D08 does not replace this helper with a generic requests proxy because that would change process/network behavior.

## 10. Update/helper architecture

```text
Info/update state
      │
      ▼
update.exe
  ├── Pixeldrain / Google Drive download
  ├── tools/7z.exe extraction
  ├── replace TLMTool.dist contents
  └── bootstrap.exe for updater self-replacement
      │
      ▼
relaunch TLMTool.exe
```

`ppx/ProxifierSetup.exe` is a separate third-party installer helper.

This path was originally established by Gate A and is only connected into the architecture here.

## 13. Critical parity constraints carried forward

The reconstruction must preserve:

1. **master HWND state != preview order**
2. **physical game grid != preview grid**
3. **layout sync != input sync**
4. **PC game path != emulator path**
5. **memory reader != injected payload**
6. **runtime config != immutable packaged payload**
7. **static reference != exact import syntax**
8. **compiled-marker interval != original source-line ownership**
9. **helper process behavior must not be silently absorbed into the main Python process**
10. **remaining runtime unknowns stay explicit until Windows/emulator parity testing**.
