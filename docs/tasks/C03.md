## 2. Source HWND và destination HWND

### Source
Mỗi preview item giữ:
- `src_hwnd`

Đây là HWND game đã qua discovery/mapping C01–C02.

### Destination
TLM không đăng ký thumbnail trực tiếp vào Tk child frame.

Binary có helper:
- `_register_dwm_dst_class`
- class name `ThlDwmThumbDst`
- `_create_dwm_dst_hwnd`
- `_destroy_dwm_dst_hwnd`

Destination được tạo bằng `CreateWindowExW` như một **transparent overlay popup HWND**.

Các style symbolic có trong helper:
- `WS_EX_LAYERED`
- `WS_EX_TOOLWINDOW`
- `WS_EX_NOACTIVATE`
- `WS_POPUP`
- `WS_VISIBLE`

Ý nghĩa kiến trúc:
- overlay là top-level popup/owned window để DWM có HWND destination hợp lệ;
- TOOLWINDOW tránh thành app-window bình thường;
- NOACTIVATE tránh preview tự cướp focus;
- overlay được đặt lên đúng vùng preview Tk.

## 3. Tk preview frame chỉ làm layout/anchor

Trong `refresh_window_preview_list`, mỗi item có:

Trước khi tạo destination HWND, code đọc geometry của preview child:

Tool top-level HWND được lấy qua:

Sau đó:
`_create_dwm_dst_hwnd(...)`
→ `DwmRegisterThumbnail(dst_hwnd, src_hwnd, ...)`

## 4. DWM thumbnail properties

Binary xác nhận helper dùng các property flags:
- `DWM_TNP_RECTDESTINATION`
- `DWM_TNP_OPACITY`
- `DWM_TNP_VISIBLE`
- `DWM_TNP_SOURCECLIENTAREAONLY`

Fields:
- `dwFlags`
- `rcDestination`
- `opacity`
- `fVisible`
- `fSourceClientAreaOnly`

Một serialized integer constant **255** nằm ngay trước `opacity`, nên opacity 255 là VERIFIED static evidence.

Destination rectangle được xây bằng `RECT` và có `max` guard để tránh zero-size dimension.

### Explicit unknown
Readable constants không chứng minh source-level assignment exact của:
- `fVisible`
- `fSourceClientAreaOnly`

Tên flags/fields chắc chắn có và được dùng; C03 không giả định boolean expression nếu chưa decompile source.

## 5. Reposition: overlay đi theo preview frame

Binary có:
- `_schedule_window_preview_reposition`
- doc: `Schedule reposition after resize (debounced).`
- `_reposition_window_previews`
- doc: `Cập nhật vị trí DWM destination windows theo kích thước frame preview.`

Trong path này xuất hiện:
- `winfo_viewable`
- preview frame
- `HWND_TOP`
- module-level `SetWindowPos`
- `SWP_NOACTIVATE`

Kết luận VERIFIED:
- DWM destination HWND không cố định;
- khi Tk layout/resize thay đổi, overlay được di chuyển/resize theo geometry hiện tại của preview frame;
- reposition được debounce để tránh spam khi Configure liên tục.

Exact native flag OR-expression của `SetWindowPos` không được tuyên bố nếu static readable table không đủ.

## 6. Click preview → activate đúng game HWND

Destination window class có custom WndProc:
- `_register_dwm_dst_class.<locals>.wnd_proc`
- global map `_dwm_dst_click_targets`

Serialized tuple ngay trong WndProc:
- 513 = `WM_LBUTTONDOWN`
- 514 = `WM_LBUTTONUP`
- 515 = `WM_LBUTTONDBLCLK`

WndProc lookup destination HWND trong `_dwm_dst_click_targets`, kiểm tra source bằng `IsWindow`, rồi gọi:
- `_activate_game_window`

Activation helper chứa:
- `IsIconic`
- `ShowWindow`
- `SW_RESTORE`
- `SW_SHOW`
- `SetForegroundWindow`

Do đó click vào live preview overlay được chuyển thành thao tác đưa **source game HWND tương ứng** lên foreground; nếu minimized thì có restore path.

Tk title/preview widgets cũng bind `<Button-1>` tới closure `_make_activate`, nên cả vùng UI Preview và overlay HWND đều có đường activate source.

## 7. Hung-window handling

`TLMStartTab._is_hung` dùng:
- `IsHungAppWindow`

Original doc:

`Kiểm tra nhanh window có bị treo (không phản hồi) hay không. Không block — IsHungAppWindow trả về ngay từ trạng thái nội bộ.`

Trong `refresh_window_preview_list`, hung check nằm trước root geometry / destination-window creation / DWM registration, và binary có visible error text:
- `Cửa sổ không phản hồi`

Error paths khác:
- `Đã đóng cửa sổ: ...`
- `Preview lỗi: ...`
- error color `#ff5555`

Kết luận:
- preview builder kiểm tra hung source trước khi làm DWM setup;
- hung/error state được hiển thị trong preview item thay vì cho thao tác blocking làm treo Tk UI.

## 11. Core C03 flow

```text
game HWND (src_hwnd)
↓
Tk preview item/frame is built
↓
_is_hung(src_hwnd)
├─ hung/error → error text in preview item
└─ responsive
   ↓
   preview.winfo_rootx/y/width/height
   ↓
   create ThlDwmThumbDst overlay HWND (dst_hwnd)
   ↓
   _dwm_dst_click_targets[dst_hwnd] → src_hwnd
   ↓
   DwmRegisterThumbnail(dst_hwnd, src_hwnd)
   ↓
   DwmUpdateThumbnailProperties
   ├─ destination RECT
   ├─ opacity 255
   ├─ visible flag field
   └─ source-client-area-only field
   ↓
   live DWM preview

resize/layout
→ debounce
→ SetWindowPos dst HWND to current preview-frame geometry

left click on destination overlay
→ custom WndProc
→ lookup src HWND
→ restore/show if needed
→ SetForegroundWindow(src_hwnd)

destroy/rebuild
→ DwmUnregisterThumbnail
→ remove click-target mapping
→ DestroyWindow(dst_hwnd)
→ destroy Tk frame
```
