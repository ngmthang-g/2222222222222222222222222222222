- 1 px lighter top/left edge
- 1 px dark/black right/bottom edge
- fill one pixel inside

Examples:
- `#388E3C` → highlight `#9CC79E`
- `#4169E1` → `#A0B4FF`

Original construction repeatedly uses raised classic buttons, so rebuild should use the relief behavior rather than treating highlight shades as separate semantic colors.

## Rendering tolerance rule
ClearType fringe pixels and some native ttk details are environment-sensitive. Strict comparison should target:
- major fills
- structural 1 px borders
- control bounds
- text placement/envelopes

Environment-sensitive comparison should tolerate:
- ClearType RGB fringes
- native ttk arrow anti-aliasing
- scrollbar arrow anti-aliasing
- non-client/titlebar rendering
