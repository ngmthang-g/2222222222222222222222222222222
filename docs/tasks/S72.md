### Implemented narrowly
- New \`src/detached_list_observer.py\` provides owner-thread-only
  \`C14DetachedListObserver.observe(snapshot,max_windows,allowed)\`.
- Never creates Tk, schedules any timer or starts/stops the **Start-only**
  \`TkStartCachePoller\`. An externally controlled, independent authorized
  producer must supply immutable snapshots if detached monitoring is later
  wired while Start is hidden. No hidden 1s/2s/3s detached poller is guessed.
- Source HWND+PID ordered tuples are a deliberately conservative **S72
  local policy**, NOT asserted exact original equality implementation.
  Identical HWND/PID with a newer revision and a different window title
  does not invalidate. Changed HWND, reused HWND with different PID,
  changed list/order first invalidate old native DWM BEFORE accepting new.
- Cache invalidation, permission revocation, unavailable verified cap,
  duplicate HWNDs, wrong game-process candidate and stale/reused revisions
  clear the observer and request **fail-closed** renderer cleanup.
  Native cleanup exceptions or explicit failure codes are surfaced;
  do not falsely report ready/changed on native teardown failure.
- Explicit reset/shutdown releases previously used preview state, checks
  owner Tk thread, and never auto-restarts. Native HWND/PID/exe/class/title
  are revalidated at actual render boundary by S68/S70, NOT faked here.
- Observer does not render any preview or automatically open a detached
  host because original per-item placement / auto-open lifecycle are unknown.
- No Proxy work, credential/game input, license bypass, hidden injection,
  rebuilt full launcher, fake \`Tách rời\` button or UI style change.
