## 1. Python runtime — VERIFIED

Bộ TLM dùng **CPython 3.10.11 x64**.

Bằng chứng trực tiếp:

- `TLMTool.dist/python310.dll` có `FileVersion` và `ProductVersion` = **3.10.11**.
- DLL có build marker `Release_v3.10.11_20230405.0`.
- `TLMTool.dist/TLMTool.exe` chứa đầy đủ chuỗi runtime:

  `3.10.11 (tags/v3.10.11:7d4cc5a, Apr  5 2023, 00:38:17) [MSC v.1929 64 bit (AMD64)]`

- `python310.dll` là PE32+ x86-64.
- Inner `TLMTool.exe` import trực tiếp `python310.dll`.

### CPython compiler

Runtime Python chính thức được build bằng **MSVC / MSC v.1929**, tương ứng PE linker header **14.29** của `python310.dll`.

Điểm này phải tách khỏi compiler dùng để build executable Nuitka: hai compiler không giống nhau.

`GCC: (MinGW-W64 x86_64-msvcrt-posix-seh, built by Brecht Sanders, r6) 15.2.0`

Kết luận:

- Compiler family: **GCC / MinGW-W64**
- Architecture: **x86_64**
- Runtime model trong producer string: **msvcrt-posix-seh**
- GCC version: **15.2.0**
- Build distribution marker: **Brecht Sanders, r6**

PE optional header của inner `TLMTool.exe` báo `MajorLinkerVersion=2`, `MinorLinkerVersion=46`. A04 chỉ ghi đây là **PE linker header value 2.46**, không tự gán thêm provenance nếu không có bằng chứng trực tiếp.
