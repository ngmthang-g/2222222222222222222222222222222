## 3. Exact HP gate is 50 percent

The treatment block directly contains:
- field `HpPercent`;
- exact threshold **50**;
- `HP ... % ≥ 50% → bỏ qua trị liệu`;
- `% < 50% → thực hiện trị liệu`;
- `không đọc được HP → vẫn trị liệu`.

The exact behavior is:

- readable HP% **>= 50** → treatment is skipped;
- readable HP% **< 50** → treatment runs;
- HP cannot be read → treatment still runs.

This is fail-open for healing, not fail-open for a destructive action.

`self, hwnd, stop_check, ci, hp_pct, map_id, coords, heal_tile_x,
