## 10. Plan-controlled row visibility

- `_hidden_rows`
- `_get_row_limit`
- `apply_account_row_limit`.

Exact documentation:
- plan decreases → hide excess rows into `_hidden_rows` preserving FIFO order;
- plan increases → restore hidden rows first, then add blank rows if still needed;
- applied when server payload/plan updates.

Thus:
- logical row capacity = 100;
- currently visible/active row count can be plan-limited.
