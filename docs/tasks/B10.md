## 4. Static populated account-row structure
Original `rao_tab.py` contains row UI/state facts:
- per-account play/toggle glyph: `▶`
- character label
- state label initialized to `Đã dừng`
- **4 Rao-content combobox slots per account**
- saved slot selections restored by character name
- only Rao names that still exist are reapplied

Original module documentation states:
- one Rao slot runs its own independent loop;
- maximum **4 slots run in parallel per account**;
- each slot sends its chosen content, sleeps for that Rao row's interval, then repeats;
- deleting/invalidating a Rao row can stop that slot.

No populated account-row pixels are invented because the screenshot is empty.
