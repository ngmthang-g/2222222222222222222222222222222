## 5. Current multi-group JSON format

`Dữ liệu đầy đủ từng cụm để lưu config:
[{'num': n, 'members': [...]}, ...]`

Therefore `party_groups` is the current multi-group representation:
- JSON list;
- one object per Party cluster;
- each object includes cluster `num`;
- each object includes `members`, a list of selected character names.

The save block directly contains:
- `json.dumps`
- `ensure_ascii`
- serialized False.

So Party writes its JSON with:

`ensure_ascii=False`

preserving Vietnamese/Unicode names rather than forcing \u escapes.

Exact JSON whitespace/separator formatting uses the normal helper/default behavior and is not independently specified by Party.
