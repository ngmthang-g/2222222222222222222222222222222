## Source review discovery — actual cross-tab blocker

- Original old `src/start_polling.py` `TkStartCachePoller._stop_refresh()` calls `producer.stop()` when Start is hidden. `StartWindowProducer.stop()` invalidates shared `WindowSnapshot` immediately and sets `active=False`.
- Existing Party `src/party_roster.py` reads `start_producer.read_snapshot()` on 3s cadence but does NOT independently start a stopped S09 producer on Party tab entry; similarly Train/Login need up-to-date physical HWND/PID. Therefore switching out of Start can lose all real game-window inputs even when there are live game windows. Source-level evidence, not a measured Windows/game outcome.
- The independent product must keep one native Win32 discovery cache globally live while each tab's Tk UI refresh/preview lifecycle can be started/stopped normally. Historic TLMTool.py/StartWindowProducer tests remain unchanged.

## Actual staged source modifications

1. **NEW `src/tlm_existing_game_reader.py`**: `ExistingGameOriginalReader.inspect(GameWindow)` is a real game-native read-only diagnostic for a **pre-existing** S09 native game window, unlike S196–S198's own-launched Popen registry. Requires active valid Start `WindowSnapshot` with fresh `captured_at` (local 7s safety bound), exact unique HWND/PID, real native `EnumWindows`+PID+Unity class/title+executable and an explicitly selected F04 game exe path. Afterwards checks Start window set, local game directory and fresh native HWND/PID. It accepts a no-op 3-second Start snapshot refresh if the entire real immutable HWND/PID window set is unchanged, never accepts a changed window set. Returns only `ORIGINAL_READONLY_CHARACTER_CANDIDATE_UNVERIFIED` with all `role_name_confirmed_for_party/account_authenticated/gameplay_action_authorized=False`, never a fake RoleReading.
2. **NEW `src/independent_shared_window_source.py`**: `IndependentSharedWindowProducer(StartWindowProducer)` holds one lifetime lease in the new tool; tab-level `stop()` no longer destroys the shared native game-window source when changing tabs. Explicit `shutdown()` invokes original `StartWindowProducer.stop()` to actually release the worker. Start's own Tk consumers/preview cleanup are unaffected. Historical original entrypoint/poller and license comparison source untouched.
3. **UPDATED `src/TLMToolIndependent.py`**: uses `IndependentSharedWindowProducer`, starts native discovery at independent app bootstrap (not on every tab activation), passes SAME producer to independent Login/Party/Train/Start; always calls `producer.shutdown()` in final cleanup even after an exception. Menu presentation capped to 30 rows per popup (not a game account cap), with remaining count warning to inspect Start. Native result is shown only as detailed diagnostic status, not a logged-in character; selection/path changes invalidate or reject stale reports. No original F04 row overlap or new gameplay button.
