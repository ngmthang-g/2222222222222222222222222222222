## Implementation
- NEW `src/adb_offline_intake.py`:
  - `CapturedAdbFrame` accepts offline already-captured ADB text, captured monotonic time, optional preobserved per-serial `GuestIdentityHint` data and `HintTimes`, optional caller-observed reboot markers. **It does not run ADB**.
  - `OfflineAdbIntake.ingest(frame,now)` strictly calls **S31 `inspect_captured_adb_devices` → S32 `with_hint_times` → S33 `advance_serial_epochs`**, in that order. Rejects malformed, absent, future/stale locally timed and duplicate serial captures; refuses invalid hint timestamp, invalid reboot marker or nonincreasing/replayed capture. **Every rejected frame clears prior epoch history** so next valid intake must establish a fresh baseline instead of reusing previously cached aid/IP.
  - `OfflineAdbIntake.lookup(field,value,now)` calls **S33 `SerialEpochSnapshot.unique_serial_for` only**. No public façade `serial_for_aid` pointing at weaker S31 or unqualified S32 lookup. Any unique serial is `IdentityLookup(code="UNIQUE_DIAGNOSTIC_ONLY")`, explicitly `may_control_device=False`.
  - `replay(frames,now)` processes in supplied order, without sorting or hiding duplicates, and invalid frames visibly break history; `last_receipt` exposes only immutable metadata, no low-level S31/S32 original wrappers. Python internal source can still be imported by other modules; this is a *convenience safety façade*, **not a sandbox, cryptographic authenticity or proof external callers cannot bypass it**.
