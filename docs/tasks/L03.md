## Main findings
- Exact options: blank, Phù 1, Phù 2, Phù 3, Ngựa.
- Exact defaults: Phù 1 → Phù 2 → Phù 3 → Ngựa.
- The blank option is an intentional disabled/unused priority slot.
- Priority controls are readonly comboboxes.
- `_on_nav_priority_changed` carries `used/current/available` state and recomputes available choices, preventing new duplicate nonblank selections through the normal UI.
- A pre-existing duplicate from hand-edited/legacy config is kept as an explicit migration/runtime microcase rather than guessed.
- Persistence keys are `[DonVang] nav_priority_1..4`.
- `_get_nav_priority` is the adapter into `move_character(home_priority=...)`.
- Shared `move_character` interprets Phù entries as ordered return-home hotkey attempts; `Ngựa` is the ordinary movement fallback.
- In Dồn, `home_priority` is wired only in `_sell_acc`.
- L02's Dồn/receiver final leg remains normal horse movement with no phù.
- Packaged log has no correlated priority-attempt trace, so live timing/failure parity remains environment-required.
