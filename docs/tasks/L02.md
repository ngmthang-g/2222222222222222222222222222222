## Main findings
- Return trigger mode is exact: cycle or full-bag.
- Cycle default is 30 minutes and the farm loop has minute-to-seconds timing evidence.
- Full-bag mode checks memory bag state, filters before Dồn, stays at farm if filtering frees space, and continues return/Dồn only if still full.
- Donor accounts replace the normal return-to-town step with the Dồn callback.
- _resolve_truyen_back uses current MapID first, farm preset fallback on memory-read failure, executes a map-specific back route, invalidates cache and verifies fresh exit.
- No route means normal movement.
- Failed shortcut verification means stop if requested, otherwise walking fallback.
- _run_farm_exit then moves to Dồn/receiver target by normal horse movement with no phù.
- Normal sell return is separate and passes _get_nav_priority() into move_character as home_priority; exact priority ordering is deferred to L03.
- Automatic return honors the farm-cycle stop callback; manual movement is rejected while auto-farm is active.
- Packaged log has no correlated Dồn return trace, so runtime parity remains environment-required.
