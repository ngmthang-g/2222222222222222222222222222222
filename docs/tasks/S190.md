Uses the **same retained actual Popen process** and validated HWND for the single most-recently independently launched game; re-enumerates native visible Win32 HWNDs and re-checks game executable/class/title/PID before each S159 normalization pass. ## Limits and acceptance blockers

- **Only the most recently launched, currently verified native game window** is normalized, because that is the only process/window the independent Login launcher can attest. Original F05 may resize multiple Login-owned windows; no parallel multi-account Login launch ownership exists yet. Do not represent this as complete F05 parity.
- A legitimate independent game may require F05's original suspended + injected loader/profile startup. S190 cannot change that, and resizing Windows HWND alone does not make login/characters/gameplay functional.
- Win32 resize outer-vs-client mathematics, DPI scaling, off-screen and hostile native windows require **actual owner game/Win64 acceptance**; source-only is NOT proof that dimensions are correct or operations succeed in the live client.
- Original license token/heartbeat, injected DLL, proxy, unauthorized game memory writes or fake accounts are excluded. Frozen `PLAN.md`, `SCOPE_LOCK.md`, DATA-2222 read-only repo and original TLM ZIP/EXE untouched.
