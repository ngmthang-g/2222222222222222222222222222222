## New verified-lifetime component
- NEW `src/login_schedule_lifetime.py` class `F09ReadOnlyTabLifetime`, **test-owned lifecycle coordinator**, not installed in production `src/login_tab.py`.
- Explicit `start_preview_and_evaluation()` activates only two previously working **read-only** components from S40 strict settings. It never enables from unknown persisted `schedule_on`/shutdown booleans, never dispatches real game actions, Proxy, Windows shutdown, or account writes.
- Binds a *second* real Tk `<Destroy>` observer with `add="+"` preserving S44's own handler and other bound handlers. Only its exact owned Label triggers `close()`; unrelated destroyed child/parent events are ignored until actual Label destruction.
- `close()` sets a permanent closed latch first, invokes preview `shutdown()` and worker `shutdown(timeout=0)`: the cancel Event is set immediately without joining a blocked 20-second worker on Tk main thread. Reports `CLOSED` or `CLOSING_WORKER`, with no falsely completed claims. A source callback still stalled can be handled after GUI teardown with `finish_close(timeout)`, which joins worker **without accessing Tk**, then transitions to CLOSED. No start can occur after closing, even with a reentrant time provider or a widget destroyed during worker startup.
- Preview startup failure rolls back without worker startup. Worker startup failure stops the preview. No duplicate start, no synthesized action permission, no signed Info bypass, no fake scheduler UI or user-facing Login button.
