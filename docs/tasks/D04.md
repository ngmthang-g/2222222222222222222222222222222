## 5. Dependency direction constraints for reconstruction

The graph strongly suggests the following safe reconstruction direction:

```text
UI/orchestrators
    ↓
feature automation modules
    ↓
shared guards/data/helpers
    ↓
memory / HWND / injection / pixel / forwarder primitives
```

Emulator modules form a parallel adapter path that reuses shared farm/permission/data logic rather than replacing PC modules.

This is an architecture constraint, not a request to refactor the original behavior.

## 6. Cycles are expected

The recovered reference graph contains apparent cycles, e.g. feature modules referencing `start_tab` while `start_tab` also coordinates feature modules.

D04 does **not** "clean up" these cycles. Reconstructed parity should preserve shared-ref/late-binding behavior where necessary instead of forcing an acyclic design that changes lifecycle semantics.
