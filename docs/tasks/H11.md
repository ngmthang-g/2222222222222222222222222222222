## 7. Current settings section and coordinate key family

Saved coordinates live in the shared settings backend:
- section `Farm`.

Save-side constants directly expose:
- prefix `coord_`
- loop/index local `_n`
- current-row locals `name/mid/x_v/y_v`.

The save contract is therefore a sequential coordinate key family:

`coord_1, coord_2, coord_3, ...`

rewritten from the current dynamic coordinate rows.

This is independent from the preset's display name, so renaming a preset does not require the INI option key itself to be the preset name.

No independent persistent UUID field is recovered for a coordinate row.

## 8. Coordinate value schema is a four-field pipe record

The shared parser directly contains:
- `split`
- literal delimiter `|`
- exact return contract:
  `(preset, mid:int, x, y) hoặc None`.

Farm save-side constants contain the same shared map-ID helper plus the row values.

The current coordinate config value contract is therefore:

`preset_name | map_id | x | y`

as one four-field pipe-separated record.

Map ID is normalized to int by the parser.

X/Y are passed through as the coordinate fields rather than being given an H11-only numeric rewrite rule.

## 11. Rename propagation is immediate

`Cập nhật danh sách lựa chọn combobox Bán/Farm của mọi acc
