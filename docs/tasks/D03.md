## 1. Evidence policy

- **PRESENT**: package/module/native file exists in D01 inventory or frozen distribution.
- **VERSION_EXACT**: a package version literal is adjacent to its package version field/module in the original EXE, or a PE File/ProductVersion is read directly from that dependency binary.
- **DIRECT_TLM_REFERENCE**: an exact-marker TLM compiled module contains a tagged reference to the dependency family, using the same conservative static relationship rule as D02.
- **TRANSITIVE/BUNDLED**: package is present but no direct internal reference was recovered; D03 does not pretend that presence alone proves direct TLM use.

## 10. Reconstruction implications

A parity environment should preserve:
- CPython 3.10.11 x64 from Gate A;
- the exact-version packages above where version evidence is strong;
- pywin32 binaries compatible with the observed 3.10.312.0 resources;
- native extension architecture x64;
- the same separation between directly used dependencies and transitive bundled dependencies.

Do not upgrade packages merely because newer releases exist. Version changes can alter WinAPI wrappers, listener behavior, TLS, image handling, and DWM/input semantics.
