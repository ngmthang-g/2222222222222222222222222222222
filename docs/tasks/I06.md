## 2. Exact mode values, labels, default and mappings

The frozen shared bag_filter constants are exact:

Modes:
- `none`
- `weapons`
- `all`.

Labels:
- `none → Không`
- `weapons → Chỉ vũ khí`
- `all → Tất cả`.

Default:
- `KEEP_MODE_DEFAULT='all'`.

Exact preset-key mapping:
- `none → ['discard_weapons','discard_nonweapon']`
- `weapons → ['discard_nonweapon']`
- `all → []`.

TrainLSV aliases this shared keep-mode contract into the pickup-mode UI layer.

Thus:
- **Không** means keep nothing from the Train discard policy: enable both weapon + nonweapon discard presets;
- **Chỉ vũ khí** means keep weapons: discard nonweapon only;
- **Tất cả** means keep everything: preset-key list is empty and the shared helper performs no discard.

Default TrainLSV behavior is therefore **Tất cả / no discard**.
