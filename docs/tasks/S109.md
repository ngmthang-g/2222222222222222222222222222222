- Added `TLMAccountRows.apply_account_row_limit(limit, *, allowed)`, strictly Tk-owner-thread; input must be an explicit integer **1..100** with external callback returning exact `True`. **1..100 is a conservative local safety range, not proof of original server plan tiers**; no signed provider or entitlement is created, and no automatic plan-change event is wired.

- Increasing limit restores hidden widgets with `grid()` in original slot order, restoring row height 35px. `hidden_row_indices` exposes only logical 0-based indices, never credentials; hidden 3..99 are restored 3,4,5,... in order. Updates canvas scrollregion after changes.
- Existing original F03 password masking still acts on all 100 hidden/visible password entries; preserving stored values and previously entered selection state. `active_visible_indices()` is an **observational presentation-only list**, not authorization of a game launch.
- No new login/play/proxy button, no persistent Settings.accounts writes, no guessed F02 check-token interpretation or legacy `Có` migration; S25 directory chooser and S37/S38 test-passing code otherwise unchanged. `allowed` on tests is explicitly TEST ONLY and does not implement signed Info.
