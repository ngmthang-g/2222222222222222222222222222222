## 7. Exact current coordinate value schema

Frozen shared `utils.parse_coord_value` contains:
- delimiter `|`
- `split('|')`
- exact slice `parts[:-3]`
- `parts[-3]`
- `parts[-2]`
- `strip`
- exact doc:
  `Parse 1 dòng coord config mới. Trả (preset, mid:int, x, y) hoặc None.`

This binds the current record structure as:

`preset_name | map_id | x | y`.

More precisely, the parser treats the **last three** pipe-separated fields as:
1. map ID
2. X
3. Y

and the preceding field(s) belong to the preset name.

Therefore a preset name containing a literal `|` can still be parsed by reassembling `parts[:-3]`; this is why the parser is not a naive exact-four-token split.

Map ID is normalized to integer. X/Y are not given an I10-specific integer rewrite.
