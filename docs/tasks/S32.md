## 2. Exact implemented scope
- **NEW `src/adb_hint_provenance.py`** consumes **only an existing S31 parsed capture** and a caller-supplied **independent monotonic timestamp for EACH optional hint field on EACH serial**. No adb.exe, subprocess, ADB daemon, Frida, network requests, APK installation, emulator/game process execution or Proxy activity.
- `HintTimes` stores `android_id_at`, `hwid_at`, `guest_ipv4_at`, `guest_game_pid_at` separately; default `None` means **unknown**, not capture timestamp. `with_hint_times` copies into a read-only mapping, refuses invalid timestamps, timestamps newer than the capture, timestamps without a corresponding value, unknown serial keys and invalid mappings.
- `TimedAdbIdentity.assess` checks **capture** freshness, provenance integrity, duplicate serial, online status, presence of hint, **hint-specific freshness** and clock order independently. Returns explicit statuses `FRESH_HINT_DIAGNOSTIC_ONLY`, `STALE_HINT`, `TIMESTAMP_UNKNOWN`, `TRANSPORT_NOT_ONLINE`, `CAPTURE_NOT_FRESH` and invalidity reasons.
- `TimedAdbIdentity.unique_serial_for` demands every online peer have a **fresh observation of that same identity field**, so stale/unknown other clones cannot make a value look spuriously unique. Even a unique, fresh guest IP is **diagnostic only**, not control authority.
- `compare_adb_lifecycle` distinguishes serial appeared/disappeared and offline→online/online→unavailable transitions. AID mapped to a different serial is **POSSIBLE_ONLY_NOT_VERIFIED** solely when both fresh snapshots contain one unique AID per online peer and old/new online serials do not co-exist. No automatic rebind, change of account ownership or device command issued.
- `emulator_account_count=None`, `combined_running_count=None`, `is_authoritative_account_total=False` always; E04's original emulator-account counting formula remains unknown. When S26 receives this incomplete count it **denies the launch preflight**.
- `HINT_LOCAL_TTL_SECONDS=30` is an explicitly **S32 local diagnostic age choice**, not the original P02 five-minute aid cache rule, not proven original behavior and not a security signature.
