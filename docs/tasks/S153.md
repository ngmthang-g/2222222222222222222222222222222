## 2. Meaningful missing functional behavior and narrow change

Prior `src/close_windows.py` S16 already performed actual native Win32 `WM_CLOSE` after fresh cached and live HWND/PID/process/class/title validation; but it expressly omitted cleanup of Unity crash handlers. The visible `Đóng hết` thus lacked a genuine original-backed side effect.

**Changed ONLY `src/close_windows.py`:**
- `NativeCrashHandlerCleaner.run()` executes precisely `("taskkill", "/f", "/t", "/im", "UnityCrashHandler64.exe")` on Windows with `shell=False`, `CREATE_NO_WINDOW`, bounded local **5s** timeout, stdout/stderr suppressed, and explicit result `TASKKILL_SENT` vs error/no-match.
- `C16CloseAll` initializes this native cleaner **only in default genuine Windows backend/poster mode**; test injection with surrogate backends does not auto-run a global process-kill.
- Invoke cleaner **exactly once after at least one fresh-verified genuine game HWND accepted `WM_CLOSE`**, including a partially valid batch. On invalid/empty/duplicate/hidden/unverified/PID-reused cache, or zero successful posts, **no global taskkill**. No unverified game/window/PID force termination.
- Preserve `CloseResult` shape and truthful `WM_CLOSE_POSTED` semantics: posting is not proof any game has exited; taskkill error is separately recorded as `last_crash_cleanup`. Clear last result at start of each request so a refused call cannot inherit a false success. Existing Start button, texts, C16 native validation and S09 preview refresh remain unchanged.
- **Important:** `taskkill /im UnityCrashHandler64.exe` is an image-name-wide Windows action. It **can forcibly end every running process with that name, even unrelated to Thần Long**. This is exactly the original recovered command semantics. This reconstructed safeguard refuses it without a verified game WM_CLOSE; it is not a per-game-child filter. The user's intentional `Đóng hết` is the action boundary. The native script must not run on a shared Windows machine where unrelated such processes are present unless the user accepts the original behavior.
