## 1. Current per-row modes
The Login row Combobox exposes exactly: `Không`, `Tool`, `Proxy`.
F01 already established the widget is readonly and the visible column label is `Ẩn captcha`.
F06 established that the selected row passes this resolved value forward as `captcha_mode`.

## 2. Runtime meaning of `Không`
The original single-row worker documentation says: `Đọc trạng thái ẩn captcha của dòng: 'Tool' → proxy thường, 'Không' → direct.`
The same worker contains exact runtime text `ẩn captcha=Không → direct`, and the multi-account path contains `Ẩn captcha=Không → direct`.

Therefore `Không` means the Login path is direct and does not request the captcha-bypass proxy path.
The row proxy/reload action is suppressed/disabled for this mode.

## 3. Runtime meaning of `Tool`
The exact single-row documentation maps `Tool → proxy thường`.
The worker also contains `_ensure_proxies_fresh`, `_start_forwarder`, `_set_forwarder_mode`, `_clear_pinned_proxy`, `_advance_forwarder_proxy`, and exact log text `DÙNG PROXY FREE`.

Therefore `Tool` selects the ordinary/free-proxy path managed by the tool/forwarder rather than a row-supplied private proxy.
Free-proxy list refresh, allocation, advance timing and forwarder files remain F08.

## 4. Runtime meaning of `Proxy`
If a row is set to `Proxy`, the Login action expects a private proxy string stored on that row.

Exact one-row failure text includes `: chọn Proxy nhưng chưa nhập proxy`.
Exact multi-account failure text includes `: chọn Proxy nhưng chưa nhập proxy → bỏ qua acc`.

The private path contains `_write_pinned_proxy` and exact log text `DÙNG PROXY RIÊNG`.

Therefore `Proxy` means use the row-specific private proxy. Missing private proxy is a validation failure/skip condition; the tool does not silently fall back to the free pool.
Pinning/file mechanics remain F08.

## 5. Per-row action button changes with captcha mode
The original `_on_captcha_mode_change` documentation is exact:
`Đổi nút reload theo combobox: Tool → ⇄ (proxy thường); Proxy → ➜ (nhập proxy riêng); Không → ẩn.`

Thus:
- Tool → `⇄` ordinary/free-proxy reload/rotate action;
- Proxy → `➜` private-proxy editor;
- Không → blank/hidden-looking action, disabled.

The compiled branch also contains `#6a1b9a` near the private-proxy `➜` state and `#e0e0e0` plus `disabled` for the `Không` state.
F01 remains authoritative for row geometry.

## 6. Selecting `Proxy` can open the editor immediately
The same method documentation continues:
`Chọn "Proxy" → tự mở popup nhập proxy ngay (từ người dùng chọn; load config không tự mở).`

Therefore:
- user-driven selection of Proxy may auto-open the editor;
- restoring saved config must not auto-open the editor.

The row constructor carries `auto_popup`, supporting this distinction.
